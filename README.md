# CORRE! — versión web

El juego corriendo en el navegador. Código fuente en el repo privado **RUN**.

## Cómo jugar

- Clic / toque = saltar (mantener para saltar más alto).

## Notas técnicas

- Export HTML5 de Godot 4.2.2, sin hilos (compatible con cualquier hosting).
- `index.wasm` se sirve en 12 partes que se ensamblan en el navegador (límite de la API de GitHub por archivo).
